# PCRadio ESP32 — упрощённая метамодель

Эта папка содержит компактную, Git-native модель проекта по мотивам
[AISMM](https://github.com/orkestron-ai/software-meta-model). Она отвечает на
семь практических вопросов перед доработкой проекта:

| b2.201 | Из каких частей состоит система? | [Архитектура](b2-system-design/201-system-architecture.md) |
| b3.302 | Где это реализовано в коде? | [Карта кода](b3-implementation/302-code-map.md) |

## Правила модели

1. Каждый существенный вывод имеет стабильный ID и ссылку на источник.
2. Непроверенные выводы помечаются как `needs_verification`.
3. Риск нельзя закрыть без проверяемого критерия завершения.
4. Новая функция начинается с impact analysis по архитектуре, поведению, рискам и тестам.
5. Факты ветки `esp32s3n16r8` нельзя автоматически переносить на бинарную версию 2.2.7.
6. После каждого рабочего цикла журнал b8.805 дополняется действиями, решениями,
   результатами проверок и незакрытыми вопросами.

## Статус

Модель является исходной точкой ревью, а не заявлением о полном соответствии
AISMM. Полный канон из 13 bundles для небольшого embedded-проекта сейчас дал бы
больше служебных файлов, чем полезного знания.
